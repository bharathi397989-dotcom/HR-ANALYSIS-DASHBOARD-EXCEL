# HR-ANALYSIS-DASHBOARD-EXCEL
HR Analytics project using Excel, Power Query, PivotTables, PivotCharts, and interactive dashboards to analyze employee attrition, workforce trends, and Employee attrition
## Project Overview

This project focuses on analyzing HR employee data using Microsoft Excel to understand workforce trends, employee attrition, and employee retention.

## Project Objectives

- Analyze employee attrition and retention.
- Understand workforce distribution across departments.
- Identify attrition trends by year, experience, and location.
- Provide actionable insights to support HR decision-making.

## Tools and Technologies

- Microsoft Excel
- Power Query – Data Cleaning and Transformation
- PivotTables – Data Summarization
- PivotCharts – Data Visualization
- Slicers – Interactive Filtering

## Key Performance Indicators (KPIs)

- Total Employees
- Attrition Count
- Attrition Rate (%)
- Active Employees
- Average Employee salary

## Dashboard Analysis

The dashboard includes employee attrition analysis, department-wise workforce distribution, yearly attrition trends, and experience-based employee analysis.

## Key Business Insights

The dashboard is designed to help identify:

- Employee groups with higher attrition.
- Trends in employee resignations over time.
- Workforce distribution across departments and locations.
- Potential areas where employee retention can be improved.

## Business Recommendations

- Investigate departments with relatively high attrition rates.
- Monitor employee retention trends regularly.
- Identify potential retention challenges across experience groups.
- Use dashboard insights to support workforce planning.
